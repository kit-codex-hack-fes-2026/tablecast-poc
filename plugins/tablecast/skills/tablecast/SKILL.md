# TableCast

接続先のOAuthログインで組織を選ぶ。最初に get_configuration で接続先の店舗設定を取得する。接続URLの storeId が省略された場合は、選択した組織で利用可能な最初の店舗になる。別店舗を指定する場合はMCP接続URLの storeId を設定する。店舗IDや金額を推測しない。

閲覧依頼では読み取りツールだけを使う。設定変更は現行版を読んでから下書きを作り、差分と検証結果を示す。公開と注文確定はユーザーの明示承認を受けてから実行する。ツールが権限不足を返したら他の店舗や認証情報で回避しない。
