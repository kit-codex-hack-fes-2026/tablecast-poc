## 変更を下書きにする

管理画面のメニュー・接客から変更を作成します。agentには対象商品と変更したい内容、根拠となる写真・表・URLを渡します。商品・カテゴリ・プラン・接客の対応言語を揃え、未確認の価格・アレルゲン・原材料を確定しません。変更対象以外の商品・画像・設定は保持します。

## お品書きから始める依頼例

> 添付のお品書きと写真からメニューの下書きを作って。税込価格、量、温度、追加料金を資料どおりに保ち、既存の商品は残して。英語・中国語簡体字・韓国語の商品名、読み、説明も用意して。食材やアレルゲンは推測せず、確認が必要な項目と変更差分を見せて。まだ公開しないで。

商品写真と料理の対応、価格や選択肢が読める資料を添えます。資料の読解はChatGPTやCodexが担当し、TableCastへの保存は接続したMCPで行います。対応言語を増やすときは日本語・英語を残し、必要な言語の設定と翻訳を追加します。保存した下書きは管理画面で確認できます。

## 接客を改善する依頼例

> 地酒の味と料理の食べ方をよく聞かれます。現在のメニューを読み、実在する商品を使った案内を3つ提案して。短い日英文案、根拠、不明点、効果を確かめる方法を添えて。味や食材は創作せず、まず提案だけにして。

店長の観察メモを一緒に渡すと、何を改善したいかが伝わります。採用する案を指定すれば下書きへ反映できます。卓上での注文やスタッフ呼出しは客向けアプリの操作です。店舗管理MCPは、その接客のもとになる設定を準備します。

## agentの保存手順

1. `get_configuration`で対象店舗と現在の設定・schemaを取得します。編集中の下書きがある場合は`get_draft_diff`で最新状態を読みます。
2. 新しい変更なら`create_draft`で下書きを作ります。
3. `update_draft`へ変更を組み込んだ全configurationと最新の`expectedVersion`を渡します。部分patchではありません。
4. `validate_draft`で検証し、`get_draft_diff`で差分を確認します。修正できるエラーは直し、保存済みの下書きID・版と保留事項を報告します。

更新・検証・公開申請には、その時点の最新の`expectedVersion`を使います。文書形式の接客指示は構造を保持し、`update_draft`に`instructionFormatVersion: 1`を添えます。店舗資料を個別toolで編集した後も、その返却版から続きを行います。

競合した場合は最新の下書きを読み直します。同じ価格などが別の変更と衝突していれば確認し、古い版で上書きしません。

## 店舗へ反映する

検証済みの保存と公開は別の段階です。公開の依頼があれば`request_publication`で返された確認画面を開きます。人が対象店舗、日英の表示、価格・必須選択、差分を確認して承認します。agentは公開ボタンの代わりに承認を偽装しません。

公開後は現行設定を再取得して反映を確認します。下書きの保存や検証成功だけを公開済みと報告しません。公開版が更新されて古い下書きを使えない場合は、新しい公開版を基に必要な変更を移します。

## 画像と売切を扱う

画像は`upload_image`で実ファイルを取り込み、返された画像キーと出所を下書きへ設定します。生成画像はイラストとして明記します。画像の取込だけでは公開メニューは変わりません。売切は販売状態の変更として扱い、商品自体を削除しません。

関連：[MCP接続](./mcp.md)、[困ったとき](./troubleshooting.md)、[目次](./index.md)。

## 変更ごとの反映時点

| 変更                                                 | 保存と反映                                                   |
| ---------------------------------------------------- | ------------------------------------------------------------ |
| メニュー・価格・売切・言語・接客・店舗資料・デザイン | 同じ設定下書きへ保存し、検証と人の公開承認後に反映           |
| ポイント方針・クーポンルール                         | 専用画面・toolで保存すると適用。メニューの公開承認は待たない |
| クーポンの手動発行・取消                             | 専用操作で実行。下書きではない                               |
| ゲーム                                               | 新しいゲーム版を登録し、検証・試遊後に管理画面で公開         |

初期設定は[はじめに](./getting-started.md)、資料の編集とZIPは[店舗資料とSkill](./store-skills.md)、翻訳と食事制限は[多言語メニューと食事情報](./menu-information.md)を参照してください。[特典](./membership.md)と[ゲーム](./games.md)は反映の手順が異なります。
