TableCastは卓上iPadから音声や画面で注文できる接客システムです。このヘルプは店舗の利用者と、店舗運営を支援するMCP agentのためのものです。ヘルプはログインせず読めます。店舗の情報や操作にはログインと対象組織の権限が必要です。

## 目的から探す

| やりたいこと                     | 案内                               |
| -------------------------------- | ---------------------------------- |
| 店舗と卓上端末を準備する         | [はじめに](./getting-started.md)   |
| Codexなどのagentをつなぐ         | [MCP接続とagentの使い方](./mcp.md) |
| 商品・価格・接客を変更する       | [設定と公開](./configuration.md)   |
| 売上や注文を調べ、改善を考える   | [統計と改善](./analytics.md)       |
| 接続・保存・音声の問題を解決する | [困ったとき](./troubleshooting.md) |

## agentから読む

公開サイトの`/llms.txt`に日英のページ一覧とMarkdownへのリンクがあります。必要な章だけ取得してください。各ページのMarkdownリンクから本文を取得でき、`/llms-full.txt`には全章をまとめています。plugin同梱版は同じ原稿を`tablecast-help/references`に収録しています。

ヘルプは操作の案内です。実際に使用できるtool、入力schema、店舗の権限・価格・公開状態は、接続中のTableCastが返す値を使って確認してください。
