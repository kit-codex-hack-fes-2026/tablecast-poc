# TableCast UI/UX刷新

関連: [客画面・テーマ #346](https://github.com/kit-codex-hack-fes-2026/tablecast-poc/issues/346)、[店舗ホーム・統計・導入 #347](https://github.com/kit-codex-hack-fes-2026/tablecast-poc/issues/347)、[版履歴・復元 #186](https://github.com/kit-codex-hack-fes-2026/tablecast-poc/issues/186)、[Storybook #336](https://github.com/kit-codex-hack-fes-2026/tablecast-poc/issues/336)。

## 標準テーマ

[6枚のコンセプト](concepts/2026-10-19/README.md)は素材感の比較に使用した。現行/Cに近い無彩色を標準にし、生成画像は素材感だけを参考にし、UI部品とレイアウトは既存画面を基本にする。主操作は塗り、補助操作は枠、選択は面、業務状態はラベルと記号を併用する。文章・表・価格は不透明な下地へ置き、透明感はヘッダーと浮いた操作面に限る。

項目内は8〜12px、同じ対象内は16〜24px、異なる対象間は32〜40pxを基本にする。操作の押下は既存CSS transition、入退場はMotionProvider配下のMotionを使う。状態は音声で読み上げず、スクリーンリーダーのlive regionにも置かない。

## 客画面とテーマ編集

客画面は従来の会話40%・メニュー60%の分割と比率調整を維持する。画像メニュー、商品一覧、商品カスタマイズ、カート、版付き確認、明示確定も既存の表示とAPIを使う。複雑なセクション編集や表示モード切替は追加しない。商品を開いた際は見出しへfocusを移し、キーボードと支援技術で編集対象を把握できるようにする。音声状態は視覚表示を保ち、自動読み上げをしない。

テーマは既存の色・書体・装飾・画像・制限付きCSS・バナー設定とschemaを維持する。設定形式の移行は不要。ロゴは従来どおり縦横比を保持する。店舗固有の配色を一括適用するボタンは削除する。保存にTanStack HotkeysのMod+Sを使い、入力検証の失敗は日英の項目名と説明を示しfocusを移す。未保存入力・409・再取得失敗を保持する。

カメラは会話ペインの鏡表示ボタンからダイアログを開く。開くだけでは撮影せず、カメラをオンにする明示操作でvideoのみを取得する。映像は端末内の鏡表示だけに用い、AIへの送信、録画、QR解析、指差し理解は追加しない。音声と独立して停止・機器変更できる。閉じる操作、非表示、pagehide、unmountで全trackを解放し、停止後に届いた取得結果も直ちに解放する。復帰時に自動再開しない。

## 店舗ホームと統計

[Shopifyの導入カード](https://mobbin.com/screens/2483d325-15ba-4b24-a732-8b468f614960)の状態と次の操作の組合せ、[期間指定と明細](https://mobbin.com/screens/4a11d92c-0225-4b80-a80d-4ce328e030f2)の階層を参考にする。TableCastでは現在の要対応と終了済み来店の集計を分け、公開メニュー・登録端末に基づく案内を置く。プラグイン導入の画像は読み取りに必要な文字を持たない装飾とし、説明と操作は翻訳可能なHTMLで示す。

統計の動きは操作の応答だけに限定する。APIにない推移や全体順位を演出せず、集計の欠損・期間・続きの有無を直接読めるようにする。客向けテーマ・注文レイアウトの簡素化方針は維持する。
