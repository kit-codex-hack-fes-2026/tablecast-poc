# TableCast UI/UX刷新

関連: [客画面・テーマ #346](https://github.com/kit-codex-hack-fes-2026/tablecast-poc/issues/346)、[店舗ホーム・統計・導入 #347](https://github.com/kit-codex-hack-fes-2026/tablecast-poc/issues/347)、[版履歴・復元 #186](https://github.com/kit-codex-hack-fes-2026/tablecast-poc/issues/186)、[Storybook #336](https://github.com/kit-codex-hack-fes-2026/tablecast-poc/issues/336)。

## 標準テーマ

[6枚のコンセプト](concepts/2026-10-19/README.md)は素材感の比較に使用した。現行/Cに近い無彩色を標準にし、生成画像のUI部品と40/60レイアウトは採用しない。主操作は塗り、補助操作は枠、選択は面、業務状態はラベルと記号を併用する。文章・表・価格は不透明な下地へ置き、透明感はヘッダーと浮いた操作面に限る。

項目内は8〜12px、同じ対象内は16〜24px、異なる対象間は32〜40pxを基本にする。操作の押下は既存CSS transition、入退場はMotionProvider配下のMotionを使う。状態は音声で読み上げず、スクリーンリーダーのlive regionにも置かない。

## 客画面と組版

メニューを主にし、会話履歴は明示的に開く。音声の停止・再開、表示切替、端末内カメラ、会話・設定、注文確認を下部に置く。会話表示は同じメニューと商品編集を保持して拡大する。言語と店員呼出はヘッダーに残す。商品、カスタマイズ、注文かご、版付き確認、明示確定の責務は既存APIに従う。

`appearance.version: 2`は任意の`sections`、`header`、`voice`を持つ。セクションは紹介、写真と文章、商品グループ、紙メニュー画像で構成する。商品グループは全商品、カテゴリ、選択商品を参照し、一覧・ギャラリー・大写真を選べる。共通のHTMLを日英・狭幅・キーボードで使い、装飾だけを店舗テーマで変える。紙メニューは既存バナーと商品リンクを使い、画像失敗でもHTMLの商品リンクを残す。全商品への入口を常に用意する。

旧色・書体・部品・制限付きCSS・画像メニューを保持する。旧組版は読込時に標準セクションとして表示し、デザイン保存でversion 2へ移る。セクションを変更するまで旧チラシの列配置も維持する。v2の下書きをv1の内容で上書きする更新はAPIで拒否する。既存の公開版、注文snapshot、テーマ外の設定を移行時に書き換えない。

店舗ロゴはTableCastの横へ置き、縦横比・透明部分を保つ。最大幅64〜320px、高さ24〜64px、間隔8〜24pxを設定できる。狭幅では上限幅をさらに縮め、取得失敗時は店名へ戻す。

音声表現はorb、共通の表情、店舗キャラクターから選ぶ。画像は登録済みassetを参照し、状態ごとの画像がなければ基本画像を使う。利用者のマイクだけを波形にし、AIのorbには出力音声と状態を反映する。現在の字幕は発話終了から5秒後に閉じ、履歴から全文を確認できる。

カメラは既定オフ。明示的な開始でvideoのみを取得し、映像は鏡表示だけに用いる。AIへの送信、録画、QR解析、指差し理解は追加しない。音声と独立して停止・機器変更でき、非表示・pagehide・unmountで全trackを解放する。停止後に届いた取得結果も直ちに解放する。表示モードを変えても再取得せず、復帰時に自動再開しない。
