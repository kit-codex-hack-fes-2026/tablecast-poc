採用方針は現行/Cに近い無彩色を基にしたTableCast標準テーマ。生成画像は色・素材感・雰囲気だけの参考とし、部品選定とレイアウトは採用しない。現在の方針と各実装Issueは[UI刷新の設計](../../ui-refresh.md)を参照する。

## 共通条件

- 店舗は京料理こもれび。既存デモの料理名・価格を使用。
- 海老と野菜の天ぷら盛合せ ¥1,180、なすの田楽 ¥580、揚げ出し豆腐 ¥610、肉じゃが ¥690。
- 注文かごは天ぷらとなすを各1品、2品・¥1,760。確認へ進む表示で、注文確定は行っていない。
- 制作時の客画面は会話40%・メニュー60%だった。後の方針変更により、この分割構造は実装には使用しない。
- 店舗画面は要対応3件、利用中8卓、空席4卓、来店中21名。期間集計は終了済み18組・42名・52件・¥64,800。
- 店舗画面の数値は比較用の合成例で、実営業の集計値ではない。

## 確認結果と実装時の扱い

6枚を目視し、店名・商品・価格・注文合計・要対応・現在の営業・終了済み来店集計・導入バナーを照合した。A客向けは写真枠の修正版を保存した。

生成画像は雰囲気を比較するための見本である。文字、ロゴ、写真枠、細かな寸法をそのまま実装仕様にしない。バナー内の例示テキストは生成表現であり、統計の対象期間や実操作成功を表すものではない。実装時は挿絵とHTMLの説明へ分ける。

生成静止画から操作・アニメーション・アクセシビリティ・性能の成功を判定していない。実装と動作確認は各実装Issue/PRの対象SHAに対して記録する。
