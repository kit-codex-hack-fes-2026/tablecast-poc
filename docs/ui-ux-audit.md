## 確認方法

- 実画面: 作業用開発環境 `http://web.359-object-identity-ux.tablecast-poc.localhost` を操作し、実API・ローカルDBを使用した。ログインは同worktreeのOAuth emulatorと既存owner fixtureを使用した。
- Browser代替: 実コンポーネント・Router・QueryClientにHTTP fixtureを接続するVitest Browser。実認証、実DB、外部サービスへの接続確認とは区別する。
- 寸法: Desktop、390×844、iPad縦相当768×1024、iPad横相当1024×768。寸法を変えたデスクトップブラウザーであり、実機iPad Safariの保証ではない。
- 評価軸: 対象と操作の近接、状態の判別、次の遷移の予測、取消とfocus復帰、同種操作の統一、意味単位の折返し。説明の追加だけで解決せず、配置・操作面・状態表示を修正した。
