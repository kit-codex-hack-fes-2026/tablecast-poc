# 韓国食堂ハヌル三条店

[デモ資料](README.md) / [店舗設定](stores.md) / [会話台本](dialogue.md) / [応答チェックリスト](paid-e2e-checklist.md)

あかりに代わる架空の韓国料理店。`tablecast-hanul`の専用組織にowner・admin・member各1名を置く。こもれびの佐藤晴香がownerを兼任し、小林直子が店長、森悠真がホールを担当する。全体は3店舗・8人・9所属である。

## 店の体験と見た目

三条で友人と料理を取り分ける、明るく気軽な食堂を想定する。青いタイル、赤い椅子、丸いステンレス卓、夕方の柔らかな照明を使う。店員は生成りのTシャツ、藍色の腰エプロン、赤い小さな名札。紙メニューは料理の写真を大きく載せ、日本語名・韓国語の読み方・英語名、辛さ、何人で取り分ける量かを短く添える。

商品写真はメニュー枠での判別を優先する。料理全体を切らずに大きく写し、余白を小さくする。器の縁は切れても料理の輪郭は残す。室内を広く写す構図は内装資料に分け、商品写真にはステンレスや黒い土鍋、光の質で店らしさを残す。

## 三人の具体的な収録

凛27歳・航29歳・葵28歳が初めて韓国料理を取り分ける別の来店テイク。日本語、3名、プランなし、空の共有カートから始める。[ja-korean-sharing](dialogue.json)の10発話で、量・食べ方・辛さの相談、注文内容の選択、300ms差の客同士の重なり、店員TTS中の割り込み、数量訂正、現行版の読み上げと明示承認を示す。

最終内容は混合葉のサムギョプサル1セット2,780円、しょうゆ酢だれのチヂミ1個1,080円、器3個のマッコリ1本880円で計4,740円。相談したスンドゥブはカートに入れない。訂正前の5,820円の内容で送信しない。

従業員の映像では、注文を受けた森悠真が卓上調理の案内に向かい、注文提供と呼出しの解除をDashboardで行う。管理者の映像では小林直子がMCPから辛さ説明や売切を下書きに反映し、差分と対象版を確認して公開する。生成した制服参考から会話アバターを設定する操作は、別Issueの構想として扱う。

## 既存データの扱い

新規DBまたは明示リセット後のseedは、あかりを作らずハヌルを作る。通常のseedは既存店舗やその来店履歴を削除しない。既存previewのあかり除去は対象店舗を確認した個別の更新として扱い、こもれび・Westwardの注文・会計・所属を保持して検証記録へ残す。
