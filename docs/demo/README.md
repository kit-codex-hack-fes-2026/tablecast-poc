# デモの店舗・ペルソナ・収録資料

[Seedとデモの実行契約](../demo.md) / [仕様索引](../README.md)

## 目指す体験

そばで相談に乗る店員と、店の個性を伝える紙のお品書きを、卓上の音声と画面で再現する。注文を急がせず、料理の違いを知り、自分たちの希望を伝え、納得して注文できることを中心にする。実際の店員が必要な判断や対応へ自然につなぐ。

京料理こもれび四条店、カスタマイズの多いWestward Burgers Kyotoを主役にする。あかりは和食の比較店舗として、別組織のメンバー・メニュー・会計が混ざらないことを確認する。架空の店舗・人物・商品・会話を使い、実店舗の紹介や実客の記録として扱わない。

## 実演と構想の区別

既存操作を通した画面を実装デモとして収録する。未実装の店舗テーマ、画像領域リンク、選択肢画像、分析MCPは構想として別の章・静止資料で示す。人物アバターは別Issueの企画だけとし、今回実装しない。

同梱する店舗の雰囲気画像は、メニュー紙面・内装・制服を検討するための生成イメージである。実装画面のスクリーンショットや実店舗の写真ではない。商品画像も生成イメージとして登録する。画像の出所・生成内容は[雰囲気画像の説明](assets/README.md)と[商品画像の説明](../../assets/demo/README.md)を参照する。

## 一卓の扱い

一つの来店セッションに複数人が同席し、一つのカート・注文確認・会計を共有する。人数は卓の確定設定、人物名は台本の参照、話者IDは音声が返した一時ラベルとして分ける。話者数から人数・席・本人・個別会計を推定しない。

模擬会話は合成fixtureであることを明示する。現在のRealtime字幕には話者IDがないため、実演時に台本の人物名を認識結果へ挿入しない。複数人の声が入る実際のマイク経路、割り込み、騒音下での聞き取りは収録前に別途確認する。
