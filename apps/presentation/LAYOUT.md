構成図の端点は主体の矩形境界、シーケンス図の端点は主体のライフラインへ接続する。全場面の文字領域、字幕帯、矢印ラベルと説明の重なり、発話の注目先、逆方向のseekをブラウザーで検査する。HyperFramesの一般的な接続検査は、シーケンスのライフラインを接続先として認識せず、detached/orphan警告を出す。警告を一括無視せず、専用検査で各主体の中心座標への一致と全編映像を確認する。構成図の端点には同じ例外を適用しない。

尺をフレーム単位で切り上げる際、浮動小数点誤差だけで1フレーム増えるケースを修正した。既存の音声尺追従テストで検出・検証。

## レイアウト障害の原因と修正（v6・記録）

Issue #1の動画生成基盤について、2026-09-12に調査。デザインの採否とは分けて、配置の破綻と検出不足を修正した。正本のCSS・生成処理を変更し、商品紹介111.1秒と技術説明60秒を再生成する。素材・台本・有料音声の再生成は行わない。

## 検査の契約

`scripts/tablecast-layout.ts` は生成HTMLをChromeで読み、実フォント・画像寸法とGSAPの指定時刻で配置を計測する。1920×1080の構成に対して、本文・ヘッダー・字幕・フッターの領域を分け、端末と説明の間隔24px以上、文字の表示枠内への収まり、親による切り抜きを検査する。これはHyperFramesの再生エンジン全体の代替ではなく、同エンジンの `check --at-transitions` と組み合わせる。

Playwrightの11件は次を対象にする。

- 商品紹介14場面・技術説明6場面について、各場面の開始直後・0.5秒後・中間・末尾の計80時点。
- 全字幕の開始境界で同時表示が1つ以下になること。
- 異なる画像比率での矢印の間隔・中心、1枚・2枚の場合の中央配置、接続先の表示後に矢印が出ること。
- 説明文の折り返しで行が伸びた場合の、次の行と選択背景の一致。
- 意図的に長すぎる見出しや親の切り抜きを作った場合、検査が不合格になること。

修正前には矢印間隔と長文のテストが失敗し、字幕時刻の単体テストも浮動小数点のずれを再現した。修正後は単体テスト27件とブラウザーテスト11件が通過した。

HyperFramesの遷移時点検査では、商品紹介212時点・技術説明98時点で配置の指摘0件、実行時・動きのエラーと警告0件だった。format・lint・typecheckも通過した。

検査は指定した領域と時点に対する契約であり、任意の台本・任意の画面比率や全フレームを保証するものではない。長すぎて領域に収まらない台本は、自動的に文字を縮めず書き出し前に不合格にする。新しい構成を追加した際は、その構成の配置契約も追加する。

## 実行と出力

```sh
bun run build:videos
bun run check:video
bun run render
```

`render:product` と `render:technical` は、それぞれ対象動画の `test:layout` を先に実行する。手動でHyperFrames CLIを直接実行した場合は、この専用検査を迂回するため、上記手順を使う。

調査ログはリポジトリの `.local/tablecast-layout-before.log`、`.local/tablecast-timing-before.log`、`.local/tablecast-v6-check-complete.log`。修正後のMP4は `output/tablecast-product-demo-v6.mp4` と `output/tablecast-technical-evaluation-v6.mp4`。旧v5は保持する。

両MP4を再出力し、FFmpegの `-xerror` 付き全編復号が終了コード0で完了した。FFprobeで1920×1080・H.264/AAC、尺111.1秒と60秒を確認。商品紹介108秒の最終MP4フレームでは、矢印の接続間隔と説明の表示を確認した。画像は `output/v6-layout-final/rendered-108s.png`。今回の記録は配置と出力の技術検証であり、デザインの評価や全編の目視レビュー完了を意味しない。

HyperFrames lintには、商品紹介の生成HTMLが382行あるという保守性の警告 `composition_file_too_large` が残る。配置・実行時エラーとは区別し、警告を隠すための圧縮や検査除外は行っていない。構成分割は今回の配置修正には含めない。

完成MP4のChrome等速再生は2本とも末尾到達・メディアエラーなし。v11の商品紹介は111.1秒、記録は output/tablecast-v11-playback.json。
