# 検証記録の保存

このフォルダーは実行時点の入力・対象版・検証結果を保持する。現在の台本・素材一覧・最新の合否は[共有手順](../SHARING.md)と各記録の対象SHA・ハッシュを照合する。

- 新しい検証は新しいファイル名で記録し、対象コード・入力・実行環境・結果・未実施範囲を残す。
- 過去の記録を現行の成功に合わせて更新しない。参照先が共有対象外でも、当時のパスとハッシュは証拠として保持する。
- 生ログ・認証状態・一時生成物はGit管理外の`.local`や`output`へ置き、共有用記録には必要な結果だけを残す。
- 削除・移管は参照元の文書と保存先を確認する独立した整理として扱う。記録の古さだけで自動削除しない。
- `experiments/tablecast-mutation`は過去の試験入力であり、兄弟cloneを指すパスを含む。現行の参照パス検査はこれを拒否する。当時の台本を書き換えて現在の生成成功を主張しない。
