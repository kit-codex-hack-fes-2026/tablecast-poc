# アプリ変更試験の検証記録

main `7d6adc7` の独立cloneに[アプリ差分](application.patch)を適用し、共通の動画基盤35ファイルを固定したまま、再収録から全編MP4生成まで実施した。元のアプリ・DB・採用動画は保持した。

## アプリの変更

| 対象           | 変更前                       | テスト用の変更後                                                             |
| -------------- | ---------------------------- | ---------------------------------------------------------------------------- |
| 客側の領域     | 会話が左、商品が右、半分ずつ | 商品が左58%、会話が右42%                                                     |
| ナビゲーション | 商品領域の上にタブ           | 下部の大きなタブと上部の3段階表示                                            |
| 商品一覧       | 2列の縦カード                | 写真・商品名・金額を並べる横カード                                           |
| GUI確認        | 確認ボタンから直接照合画面へ | メニューからリストへ進み、その後に照合。承認前には注文しない                 |
| 店員           | 概要中心のタブと空カート     | 注文受付を先頭にし、未受付・受付済み・提供済みの実件数を表示。空カートを省略 |
| 表現           | 黒基調、既存の操作名         | 緑基調、日英の操作名を変更、Labを表示                                        |

価格・注文確定・版管理・認可・音声処理は既存の実APIを使う。新しい業種や異なるバックエンドへの移植は今回の検証範囲外。

## 共有範囲と限界

完成動画と当時の入力・検証記録を証拠として残す。試験専用の原録画・編集素材・実行スクリプト・Compose環境は共有対象外で、台本の素材パスと検証記録のハッシュは履歴として保持する。このcheckoutだけから変更試験の映像を再生成できるとは主張しない。

35ファイル固定は当時の試験結果。基盤修正後のコードを当時のハッシュと照合する試験は行わない。現在のアプリへの追従は[通常ワークフロー](../../WORKFLOW.md)で新しい入力・収録・検証記録を作る。UIや文言・配置の変更を試したもので、異なる業種やバックエンドへの移植、セレクターや台本の自動修正は検証範囲外。
