## 利用シーン

`scene-consult.webp` は、組み込みimagegenで2026年10月30日に生成した架空の利用シーン。二人が料理や日本酒を相談する場面を表す。端末の画面は描かず、実画面は別のスクリーンショットで説明する。生成後は1024×683のWebPへ縮小した。

制作方法はこの資料で管理し、LP上には制作方法の但し書きを表示しない。実在の顧客、利用店舗、導入実績、第三者の推薦を表すものとして使用しない。
