# Simple Flags

日本・英国の国旗はChris Wharton作の[Simple Flags #1](https://iconstore.co/icons/simple-flags-1)から使用する2点を切り出した。図形・色は配布元のまま、viewBoxのみ旗の境界に合わせた。

配布元: https://downloads.iconstore.co/simple-flags-01.zip

[IconStoreの利用条件](https://iconstore.co/license)に従う。個人・商用プロジェクトで利用・加工でき、表記義務はない。アイコン集そのものの再配布、アイコンを製品の主価値とする利用には作者の同意が必要。本アプリでは言語切替の補助表示として2点のみ利用し、アイコン集を配布しない。

## 通貨の国旗

通貨選択の追加国旗21点は[flag-icons v7.6.0](https://github.com/lipis/flag-icons/tree/v7.6.0/flags/4x3)から必要なSVGだけを取り込んだ。EURにはEU旗を使い、既存の日本・英国旗は維持する。[MITライセンス](LICENSE.flag-icons)に従い著作権表示を同梱する。
