# OpenScreenデモ動画

**録画と編集はOpenScreenのGUIをComputer Useで操作する。** 単純なWeb画面の撮影ならCodex Browser / Playwrightを使ってよい。利用する操作スキルに従う。

PRの動作証拠は撮ったままでよい。録画後は書き出しと再生確認へ進み、見栄えのためのcut・字幕・zoomは追加しない。以下の編集手順は、デモの編集を依頼された場合に使う。

## 録画と編集

1. 見せたい操作と結果を決め、対象ウィンドウを録画する。通知、認証情報、無関係なウィンドウを映さない。
2. 既存素材は元projectとmediaを残してコピーを編集する。参照mediaが開けることを確認する。
3. 待ち時間や失敗操作をcutし、操作の因果関係が伝わる流れにする。cutを確定してから最終字幕を生成・修正する。
4. 重要な操作へzoomを付ける。見出し、補足、字幕が重要UIやpointerを隠さないようプレビューする。
5. 字幕の固有名詞、改行、表示時間を確認する。内容に沿って編集し、一律の時刻や位置で効果を付けない。

CLIの方が短く確実な処理だけ `openscreen help` で利用可能な機能を確認して使う。GUIとCLIでproject形式が異なる場合はGUIへ戻り、独自のJSON変換・字幕同期スクリプトを作らない。

## ナレーションが必要な場合

画面の操作順と尺に合わせて台本を作り、ユーザーが指定・許可したTTSを使う。長い一括音声が映像とずれる場合は場面ごとに合わせる。原音の置換かmixかを依頼から判断し、音声が末尾で切れないことを確認する。

GUIで厳密な原音置換ができない場合は映像を書き出し、映像と音声を `ffmpeg` でmapする。先にTTSが映像尺を超えていないことを確かめる。

```bash
ffmpeg -i "$PICTURE_MASTER" -i "$VOICEOVER" \
  -filter_complex "[1:a]apad[voice]" \
  -map 0:v:0 -map "[voice]" -c:v copy -c:a aac \
  -shortest -movflags +faststart "$OUTPUT"
```

## 書き出しと確認

MP4等へ書き出し完了を待ち、完成したファイルを再生する。冒頭・末尾と操作・結果を確認し、編集した場合はcut境界、字幕、zoom、音量、音声同期も確認する。projectのプレビューだけで納品しない。

元素材、編集project、使用した台本など再編集に必要なファイルと、最終動画を残す。

UI・エンドユーザーの振る舞い変更を示す動画はPRの関連説明中へ埋め込み、直下に操作と確認結果の短いキャプションを添える。専用の動画見出しは作らない。`github-issue-pr-ops` が利用可能ならその添付手順を使い、なければGitHubの標準アップロード機能を使う。必要に応じて元動画を残して圧縮し、添付後も再生を確認する。
