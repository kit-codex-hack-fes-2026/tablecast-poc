# テスト対応表

対象の要求・変更:

| 規則・失敗リスク | Given / When / Thenの代表ケース | 所有レイヤー（ランナー） | 接続する実物・観測境界 | 上位固有の検証 | 未検証・非自動化の理由 |
| ---------------- | ------------------------------- | ------------------------ | ---------------------- | -------------- | ---------------------- |
|                  |                                 |                          |                        |                |                        |

既存テストを削除・統合する場合:

| 既存テスト | 保証している規則と境界 | 置換先と同等な保証の根拠 |
| ---------- | ---------------------- | ------------------------ |
|            |                        |                          |

skipや一時隔離がある場合:

| 対象 | 理由・影響 | 追跡Issue・担当 | 解除条件・期限 | 代替確認 |
| ---- | ---------- | --------------- | -------------- | -------- |
|      |            |                 |                |          |

不要な表は削除する。計画時は予定、PRでは実行結果・未実施を記録する。
