## Before starting a task

Check the connected TableCast server's tool list and input schemas, the target store ID, permissions and current configuration. Do not guess store IDs or prices; ask when the supplied material and current data do not establish a fact. [Check the connection and authorisation](./mcp.md) before starting the requested task.

A request for an explanation does not authorise changes to store settings. When changes are requested, follow [Configuration and publishing](./configuration.md) and distinguish saving, validation, publication requests and human approval. Saving or successful validation alone does not mean the changes are published; check the current configuration after publication. Points and coupons apply through their own save operations, and games publish separate versions; check the relevant guide for those steps.
