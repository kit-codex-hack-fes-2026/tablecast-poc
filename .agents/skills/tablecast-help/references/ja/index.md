TableCastは卓上iPadから音声や画面で注文できる接客システムです。店舗の準備、接続、設定変更、公開、運用上の確認に必要な手順を目的別に整理しています。

## 目的から探す

| やりたいこと                     | 案内                               |
| -------------------------------- | ---------------------------------- |
| 店舗と卓上端末を準備する         | [はじめに](./getting-started.md)   |
| Codexなどのagentをつなぐ         | [MCP接続とagentの使い方](./mcp.md) |
| 商品・価格・接客を変更する       | [設定と公開](./configuration.md)   |
| 売上や注文を調べ、改善を考える   | [統計と改善](./analytics.md)       |
| 接続・保存・音声の問題を解決する | [困ったとき](./troubleshooting.md) |

## 作業前に確認する

接続中のTableCastが返すtool一覧・入力schema、対象店舗のID・権限・現行設定を確認します。店舗IDや価格を推測せず、資料と実データで判断できない点は確認します。[接続先と権限の確認](./mcp.md)を済ませてから、対象の作業へ進んでください。

説明の依頼では店舗設定を変更しません。変更を依頼された場合は[設定と公開](./configuration.md)に従い、下書きの保存・検証・公開申請・人による公開承認を区別します。保存や検証の成功だけを公開済みと報告せず、公開後の現行設定を確認します。
